# Preview images

The spectrum GIFs, social card, README banners, touch icon, and pet previews
are generated by [scripts/build-assets.py](../../scripts/build-assets.py)
from committed [audio](../../audio) and the [Rocky atlas](../../pets/rocky/spritesheet.webp).
