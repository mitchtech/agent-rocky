Sound cues for coding agents

Amaze. Amaze. Amaze.

Your coding agent, with an Eridian engineer's enthusiasm.

Agent Rocky plays Rocky's lines from Project Hail Mary when Claude Code, Codex, or Gemini CLI does something you should hear about. You get "Hello, Grace friend" when a session starts, "Amaze! Amaze! Amaze!" when a turn ends, and "We die. We die. We die." when an approval is for rm -rf. When your usage runs out, Rocky says what every engineer on a fuel budget already knows: not enough, not enough.

Destructive-command alarm

We die. We die. We die.

When an approval is for something you cannot take back, the cue changes. Recursive force deletes, force pushes, hard resets, dropped tables, mkfs, dd, and their PowerShell cousins all sound the alarm instead of the ordinary question.

It is a louder cue, not a safety check. The hook never blocks, approves, logs, or stores the command; only a yes/no flag leaves it.

agent wants to run:
$ git push --force origin main
allow? [y/n]

Usage alarms

Not enough. Not enough.

Claude Code reports why a turn failed. Rate limits, billing errors, and accounts on hold play the Astrophage line. Hitting the output token limit plays "too much." An optional status-line meter shows how much of your tightest limit is left, and Rocky asks once when the tanks run low.

Install

Two commands. Fist my bump.

Run these in your terminal. Sounds need Node.js 22+ and a local audio player; restart your agent after installation.

Claude Code

claude plugin marketplace add mitchtech/agent-rocky
claude plugin install rocky@agent-rocky

Codex

codex plugin marketplace add mitchtech/agent-rocky
codex plugin add rocky@agent-rocky

Gemini CLI

gemini extensions install https://github.com/mitchtech/agent-rocky

Review and trust the sound hooks in Codex's hook settings. Running another Agent plugin too (Navi, Johnny 5, Warcraft, Star Wars, or StarCraft)? Enable one per host so they do not talk over each other. Other agents use the standalone event interface.

Install the Codex pet

npm install -g github:mitchtech/agent-rocky
agent-rocky pet install
agent-rocky doctor --pet

These commands install the CLI and pet without enabling sound hooks. Prefer a standalone bundle? Download the pet ZIP and extract its rocky directory into ~/.codex/pets/. Then select Rocky in your host's pet picker. Installation never changes the selected pet.

Sound controls
agent-rocky status
agent-rocky mute prompt_submitted
agent-rocky unmute subagent_started
agent-rocky preset attention
agent-rocky preview fist-my-bump
agent-rocky unmute all

Or ask your agent to "mute Rocky" or "turn off amaze amaze amaze" through the bundled control skill. Global mute preserves your event preferences.

Status line

Astrophage meter

Point Claude Code's status line at agent-rocky statusline to see how much of your tightest limit and context window is left, with a cue when either runs low. Setup guide.
